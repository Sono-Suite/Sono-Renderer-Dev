# Sonolus v1.1.4 Watch/shared-runtime capability audit

This is a source-backed capability inventory and current implementation status, not a compatibility claim. The official function index exposes 157 entries, including an “Easing Functions” family; expanding that family to its 36 named variants yields 192 function names. `Execute0` is excluded from the v1.1.4 target because the official 0.7.0 release notes say it was removed. The current public function index is not itself version-pinned, so the release note is used to distinguish that historical entry.

Status meanings:

- **VERIFIED** — direct real Sonolus v1.1.4 observation for the stated behavior.
- **IMPLEMENTED_SPEC** — behavior has a clear official specification and code/tests exist; this is not a claim of full oracle parity.
- **IMPLEMENTED_UNVERIFIED** — code exists, but semantics/integration are not fully validated.
- **PARTIAL** — some documented behavior exists while a material host/backend/input path is missing.
- **MISSING** — not implemented.
- **ORACLE_REQUIRED** — docs and authorized local references do not settle a behavior that matters.
- **OUT_OF_V1_SCOPE** — belongs to a mode or feature explicitly excluded from this Watch target.

## Current changes from this audit pass

- Oracle-backed `Draw(-1)` behavior remains narrowly implemented: normal arguments are evaluated, no display command is appended, result is `0`; the test proves continuation to a subsequent valid Draw and argument side effects. `-2` remains rejected.
- `GetPointed` now follows the official nested-read equivalence; corresponding pointed writes and shifted/pointed compound variants are covered by focused tests.
- `DoWhile` is implemented as body-then-test and returns `0` on test termination.
- `While` supports the documented one-body form and retains a legacy two-argument pretest form because strict rejection broke the supplied Horizon package. The compatibility semantics need a current-client oracle test.
- `MoveParticleEffect` now updates the corners of a valid live particle instance and emits a backend-neutral move event; the operation returns `0`. Behavior for invalid instance handles and all particle visualization remain unresolved.
- `Play`, `PlayLooped`, and `StopLooped` now emit backend-neutral frame events; looping handles share the allocator used by scheduled loop operations. No immediate or looped audio playback backend is implemented.

This audit remains incomplete: stack functions, deterministic random, replay stream host provisioning, `StreamSet`, curved rendering, audio playback/mixing, and full visual particle behavior remain gaps or oracle questions.
